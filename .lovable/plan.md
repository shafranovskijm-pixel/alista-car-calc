### 4. Фикс мерцания на мобильном

Источники мерцания на dpr=3.25 (телефон пользователя):
- три анимированных «orbs» с `blur-[100px]` и `framer-motion` пересчётом каждый кадр — на мобильном жрут GPU и дёргают композитор.
- `PageTransition` + framer на каждом маршруте.

Что делаем в `BackgroundDecor.tsx`:
- На мобильном (`useIsMobile()`) отключаем анимацию орбов — оставляем их статикой с тем же blur и opacity. Десктоп — как есть.
- Уменьшаем blur с `100px` до `80px` и добавляем `will-change: transform` + `transform: translateZ(0)` для аппаратного слоя.
- Сетчатый паттерн `bg-grid-pattern` оборачиваем в слой с `transform: translateZ(0)`, чтобы не перерисовывался при скролле.

В `PageTransition.tsx` уменьшаем длительность с текущей до 0.18s и убираем `y`-смещение на мобильном (`useIsMobile`) — только fade. Это убирает «прыжок» при навигации.

В `index.css` добавляем глобально:

```css
@media (max-width: 767px) {
  .motion-reduce-mobile { animation: none !important; transition: none !important; }
}
html { -webkit-font-smoothing: antialiased; }
body { overscroll-behavior-y: none; }
```
