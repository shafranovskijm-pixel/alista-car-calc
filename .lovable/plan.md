## Цель

Сделать так, чтобы **alistaru.ru** открывался без VPN в РФ, а CRM/формы/админка тоже работали без VPN.

Схема должна быть такая:

```text
Пользователь
  -> alistaru.ru / www.alistaru.ru
  -> ваш Nginx-сервер
  -> опубликованный сайт Lovable

Сайт
  -> api.alistaru.ru
  -> ваш Nginx-сервер
  -> backend / auth / база / storage / functions
```

## Что значило «рядом»

Это не второй backend и не параллельный прокси.

Я имел в виду: **не трогать авто-сгенерированный файл Lovable**, а добавить в проект отдельный безопасный клиент, который будет использовать:

```text
https://api.alistaru.ru
```

Визуально и логически для вас это один сайт Алисты. Просто внутри кода запросы пойдут не напрямую на заблокированный backend-домен, а через ваш Nginx.

## План действий

### 1. Оставляем Nginx для API

`api.alistaru.ru` уже проверен: сертификат правильный, запросы доходят до backend.

Остаётся убедиться, что DNS `api.alistaru.ru` указывает на ваш сервер и не проксируется через чужой CDN.

### 2. Настраиваем Nginx для сайта

Для доменов:

```text
alistaru.ru
www.alistaru.ru
```

нужен отдельный server-блок Nginx, который проксирует опубликованный фронтенд:

```text
https://alista-car-calc.lovable.app
```

Так пользователь в РФ будет открывать сайт через ваш сервер, а не напрямую через Lovable.

### 3. Меняем DNS

У регистратора домена должны быть записи:

```text
alistaru.ru      A      176.98.178.203
www.alistaru.ru  A      176.98.178.203
api.alistaru.ru  A      176.98.178.203
```

Если используется Cloudflare или похожий сервис — для этих записей нужен режим **DNS only**, без проксирования.

### 4. Выпускаем HTTPS-сертификаты

На сервере выпускаем/проверяем сертификаты Let's Encrypt для:

```text
alistaru.ru
www.alistaru.ru
api.alistaru.ru
```

### 5. Правим проект Алисты

В проекте нужно сделать только одно: чтобы весь frontend обращался к backend через:

```text
https://api.alistaru.ru
```

Для этого:

- создаём отдельный клиент backend-запросов;
- используем тот же публичный ключ;
- не трогаем авто-сгенерированный файл Lovable;
- переключаем импорты в коде с текущего клиента на новый.

### 6. Проверяем

После этого проверяем без VPN:

- открывается ли `https://alistaru.ru`;
- грузятся ли страницы;
- работает ли вход в админку;
- открываются ли заявки/CRM;
- отправляется ли форма заявки;
- грузятся ли фото из storage.

## Итог

Это будет та же схема, что у Синтагмы: **весь трафик Алисты идёт через ваш Nginx**, поэтому пользователю не нужен VPN ни для сайта, ни для CRM/backend.
