## Обновлённая схема

Если `alistaru.ru` тоже не открывается без VPN, то оставлять домен напрямую на Lovable нельзя. Делаем так:

```text
Пользователь в РФ
  ↓
alistaru.ru / www.alistaru.ru
  ↓
ваш сервер Nginx 176.98.178.203
  ↓
Lovable frontend
  ↓
api.alistaru.ru через тот же Nginx
  ↓
backend / база / auth / storage
```

То есть ваш сервер становится единой точкой входа:
- `alistaru.ru` и `www.alistaru.ru` проксируют сам сайт;
- `api.alistaru.ru` проксирует backend-запросы CRM;
- один сервер и один IP подходят, второй сервер не нужен;
- Nginx различает сайты по домену через `server_name`, поэтому на одном IP могут жить и Sintagma, и Alista, и API.

## Шаг 1 — DNS домена

В DNS у регистратора нужно будет поменять/добавить записи:

```text
alistaru.ru      A      176.98.178.203
www.alistaru.ru  A      176.98.178.203
api.alistaru.ru  A      176.98.178.203
```

Важно: это уже меняет маршрут основного сайта. После применения DNS сайт будет идти не напрямую в Lovable, а через ваш Nginx.

## Шаг 2 — Проверка сервера

По SSH нужно будет проверить:
- установлен ли Nginx;
- какие сайты уже подключены;
- есть ли `sites-available/sites-enabled` или конфиги лежат в другом месте;
- установлен ли certbot для HTTPS.

Я дам команды по одной, а вы будете присылать вывод/скриншот. Ничего опасного на этом этапе не меняем.

## Шаг 3 — Nginx для сайта

Создадим отдельный конфиг для:

```text
alistaru.ru
www.alistaru.ru
```

Он будет проксировать фронтенд Lovable.

## Шаг 4 — Nginx для API

Создадим отдельный конфиг для:

```text
api.alistaru.ru
```

Он будет проксировать backend/CRM-запросы, включая auth, storage, functions и realtime.

## Шаг 5 — HTTPS

Выпустим сертификаты Let's Encrypt:

```text
alistaru.ru
www.alistaru.ru
api.alistaru.ru
```

## Шаг 6 — Правка проекта

В проекте нужно будет заменить backend URL на:

```text
https://api.alistaru.ru
```

Google OAuth не используется, поэтому его не трогаем.

## Что нужно от вас прямо сейчас

Сначала делаем только DNS.

Зайдите к регистратору домена `alistaru.ru` и пришлите скриншот текущих DNS-записей. Особенно нужны записи для:

```text
@
www
api, если уже есть
```

После скриншота я скажу точно, какие записи менять, чтобы не сломать лишнее.
