## Что нужно сделать

В описаниях карточек на `/works` сейчас почти везде есть отсылки к партнёрскому каналу @AutoXvat (ссылки `t.me/AutoXvat`, `taplink.cc/autoxvat`, телефон партнёра, шапка «Авто представлены в нашем Телеграмм канале…», подпись «Мои соцсети»). Это партнёры — на сайте Алисты этих ссылок быть не должно.

Затронуто **45 из 47** карточек в БД.

## План

**1. SQL-миграция — массовая чистка `works.description`**

Одним `UPDATE` пройтись регулярками по всем записям и вырезать:

- Шапку: `❗️Авто представлены в нашем Телеграмм канале Готовы к приобретению: https://t.me/AutoXvat Доступен к покупке в … ❗️` (и варианты «в Китае/Японии/Корее»).
- Любые URL `https?://t.me/AutoXvat…` и `https?://taplink.cc/autoxvat…`.
- Подпись-хвост: `➡️ Мои соцсети: …` и далее `Заказ авто! Перегон! Вопросы! 📞 +7 953 070 74 44 📞` (в разных вариантах написания телефона и пробелов).
- Отдельно затереть оставшиеся вхождения слова `AutoXvat` / `Автохват`.
- Схлопнуть лишние пробелы/переводы строк и тримнуть.

Миграция идемпотентна — повторный прогон ничего не сломает.

**2. Проверка фронта**

В коде `/works` и `/admin/works` ссылок на Автохват нет (проверено — только в данных). После миграции в карточках останутся чистые тех. характеристики и цена. Кода трогать не нужно.

**3. На будущее (опционально, скажи отдельно если надо)**

Можно добавить в админку (`AdminWorkEdit`) маленькую кнопку «Очистить от партнёрских ссылок», которая применит ту же чистку к одному описанию — пригодится, если будешь импортировать новые посты из их канала.

## Технические детали

SQL (упрощённо):

```sql
UPDATE public.works
SET description = trim(regexp_replace(
  regexp_replace(
    regexp_replace(
      regexp_replace(description,
        '❗️Авто представлены[^❗]*❗️', '', 'gi'),
      'https?://(t\.me/AutoXvat|taplink\.cc/autoxvat)\S*', '', 'gi'),
    '➡️\s*Мои соцсети.*?(\+?\d[\d\s\-]{8,}\s*📞)?', '', 'gis'),
  '(AutoXvat|Автохват)', '', 'gi'))
WHERE description ~* '(автохват|autoxvat|t\.me/|taplink|9530707444|соцсети)';
```

(финальный regexp в миграции добью аккуратнее — с очисткой двойных пробелов и пустых хвостов вида «Заказ авто! Перегон! Вопросы!»).
