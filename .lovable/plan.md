

## План: блок нормативной документации в калькуляторе

Добавить под калькулятором раскрываемую секцию «Методика расчёта» с подробным описанием каждого платежа, формул, ставок и ссылок на нормативные акты.

---

### Что будет добавлено

Под формой калькулятора — новая секция с Accordion (5 раскрываемых блоков):

1. **Таможенная пошлина** — описание формулы для физлиц (ЕТТ ЕАЭС, таблица ставок по стоимости и объёму для новых/3-5/5+ лет) и юрлиц (% + минимум €/см³), с указанием кодов ТН ВЭД 8703
2. **Акцизный сбор** — таблица ставок по мощности (ФЗ № 425-ФЗ, ставки 2026: 0/64/613/1004/1564/1621/1678 ₽/л.с.), пояснение что физлица для личного пользования освобождены
3. **НДС** — формула: (стоимость + пошлина + акциз) × 22%, основание ФЗ № 425-ФЗ (с 01.01.2026), физлица освобождены
4. **Утилизационный сбор** — базовые ставки (20 000 / 150 000 ₽), таблица коэффициентов по объёму двигателя для новых/старых ТС, основание: Постановление Правительства РФ № 1291 в ред. № 1713 (с 01.12.2025)
5. **Таможенный сбор за оформление** — таблица сборов по стоимости ТС, основание: Постановление Правительства РФ № 1637 (с 01.01.2025)

---

### Технические детали

- **Файл**: `src/pages/Calculator.tsx`
- **Компоненты**: используем существующий `Accordion` из `src/components/ui/accordion.tsx`
- Секция размещается после grid с формой и результатом, внутри того же `container`
- Каждый AccordionItem содержит: описание, формулу, таблицу ставок (через `<table>`), ссылку на НПА
- Стилизация: `bg-card border border-border/50 rounded-xl`, таблицы с `text-sm`, zebra-striping через `even:bg-secondary/30`
