## Предлагаемый план доработок (по приоритету)

### Спринт 1 — критичные блокеры (1 итерация)

1. **Лиды с сайта → в CRM.** Сделать переиспользуемый компонент `<LeadForm source="contacts|index|calculator|car-card" />` с записью в `leads` (anon insert через RLS-политику «insert only»). Парсить `utm_source/medium/campaign/term/content` из URL и класть в новые колонки. Подключить форму на Главной (CTA-секция), в Контактах (заменить текущую), в Калькуляторе (после расчёта), в карточке авто (с автоподстановкой марки/модели).
2. **Починить сайдбар.** Либо убрать пункты «Каталог»/«Настройки», либо добавить заглушечные страницы. Подсветить активный `NavLink`.
3. **Floating CTA.** Плавающие кнопки WhatsApp + Telegram + Позвонить в правом нижнем углу на всех публичных страницах.

### Спринт 2 — каталог авто (основной продукт)

4. Таблицы `cars` (brand, model, year, engine_volume, transmission, mileage, price, currency, country: jp/kr/cn, status: in_stock/in_transit/on_order, description, auction_sheet_url) и `car_photos` (как `work_photos`).
5. Публичные страницы `/cars/japan|korea|china` со списком и фильтрами + страница карточки `/cars/:slug` с галереей, характеристиками, кнопкой «Заказать просчёт» (LeadForm с автоподстановкой).
6. Админка `/admin/cars` (список + редактор по аналогии с `AdminWorks`).

### Спринт 3 — каталог товаров из Китая

7. Таблицы `product_categories`, `products` + публичный `/goods` с категориями и формой «Рассчитать доставку».
8. Админка `/admin/goods` (категории + товары).

### Спринт 4 — документы и интеграции

9. Шаблоны документов: загрузить .docx-шаблоны (договор, поручение, акт, счёт) в `document_templates`, edge-функция `generate-document` (docxtemplater → PDF через сервис или отдача .docx), UI «Сгенерировать документ» в карточке сделки, отправка на e-mail клиента через edge-функцию `send-email` (Resend через Lovable AI Gateway / SMTP-секреты).
10. Edge-функция `notify-new-lead`: после insert в `leads` шлёт сообщение в Telegram (бот-токен + chat_id из секретов) и письмо менеджеру.
11. Вставить счётчик Яндекс.Метрики (ID хранить в `site_settings`) и события целей на отправку всех форм / клик по телефону / переход в мессенджер.

### Спринт 5 — отчёты и админ-CMS

12. Отчёты: по источникам (`source` + UTM), по менеджерам (assignee), экспорт CSV/XLSX заявок и сделок.
13. CMS-блок: таблица `site_content` (key/value JSONB) для текстов главной, преимуществ, FAQ, баннеров; страница `/admin/content` с формами.
14. Виджет «Перезвоним за 5 минут» (модалка по таймеру/кнопке) и управляемый поп-ап спецпредложения (вкл/выкл + текст в `site_settings`).
15. Страницы `/privacy` и `/consent`.

## Техническая часть (детали реализации)

- Все новые таблицы: GRANT согласно политике, RLS вкл., `anon` только на `insert` для `leads`/форм и на `select` для публичных каталогов (cars, products со статусом «published»).
- Колонки `leads`: добавить `source text`, `utm_source/medium/campaign/term/content text`, `object_interest text`, `messenger text`.
- Storage-бакеты: `cars` (приватный, signed URLs как у works), `goods`, `documents` (уже есть).
- Edge functions: `notify-new-lead`, `send-email`, `generate-document` — все в `supabase/functions/*`, верификация JWT для генерации/отправки, публичный invoke для notify (вызывается из триггера БД через `pg_net` или из клиента после insert).
- Секреты: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `RESEND_API_KEY` (или SMTP), `YANDEX_METRIKA_ID` (последний — в `site_settings`, не секрет).
- Использовать Lovable AI Gateway / Lovable Cloud, без сторонних провайдеров без согласия.
