# Коммерческие предложения (КП)

Новый раздел CRM для создания, редактирования и отправки красивых коммерческих предложений в фирменном стиле Alista.

## Что появится в интерфейсе

**Сайдбар → группа «Продажи» → новый пункт «Предложения»** (иконка FileSpreadsheet).

### Страница `/admin/offers` — список КП
- Таблица: № · Клиент · Заголовок · Сумма · Статус (черновик / отправлено / просмотрено / принято / отклонено) · Дата
- Кнопка «Создать КП» → мастер
- Фильтры по статусу и клиенту, поиск
- Действия по строке: открыть, дублировать, скачать PDF, отправить email, удалить
- HintCard: объяснение, зачем этот раздел

### Мастер создания `/admin/offers/new` (и редактирование `/admin/offers/:id`)
Экран из трёх колонок на десктопе, вертикальный на мобильном:

1. **Слева — параметры**
   - Клиент (поиск по существующим из `clients` + быстрое создание)
   - Заголовок КП, комментарий/вступление
   - Валюта (RUB/USD/EUR), НДС вкл/выкл
   - Срок действия (дней)
   - Выбор шаблона: 3 варианта карточек-превью

2. **Центр — каталог услуг с добавлением в КП**
   - Готовый пул услуг из справочника (см. ниже), сгруппированный:
     - Таможенное оформление (подача ДТ, СВХ, брокер, сертификация, ЭПИ, оплата пошлин)
     - Логистика (доставка авто из Японии/Кореи/Китая, ж/д, автовоз)
     - Лаборатории и экспертизы (СБКТС, ГЛОНАСС, ЭПТС, лабораторные испытания образцов)
     - Дополнительные (перевод, хранение, страхование)
   - Клик по услуге → добавляется в правую панель как позиция
   - Кнопка «Добавить свою услугу»

3. **Справа — состав КП (позиции)**
   - Строки: название · описание · кол-во · цена · сумма · удалить
   - Все поля редактируются на месте
   - Итого / НДС / К оплате
   - Кнопки: «Сохранить черновик», «Предпросмотр», «Скачать PDF», «Отправить на email»

### Предпросмотр КП (модалка)
Рендер выбранного шаблона с реальными данными, кнопки «Скачать PDF» и «Отправить».

### Отправка
Диалог: получатель (по умолчанию email клиента), тема, сопроводительное письмо, вложение PDF. Отправка через существующую edge-функцию `send-smtp-email`. После отправки статус меняется на «Отправлено», в тайм-лайн клиента и сделки пишется событие.

## Три шаблона в стиле Alista

Оформление совпадает с сайтом: тёмный премиум-фон, неоновые синие акценты, Space Grotesk для заголовков, Inter для тела. Все три — на A4, готовые к печати/PDF.

1. **«Premium Dark»** — тёмный фон, крупный заголовок, светящаяся линия-акцент, таблица позиций с blue-glow строкой итога, футер с реквизитами ООО «Алиста».
2. **«Clean Light»** — белый фон, тонкая синяя рамка и синий заголовок-баннер, минималистичная таблица, аккуратный блок «Что входит» иконками.
3. **«Executive»** — двухколоночный титульный лист с большим номером КП и брендингом, вторая страница — детальная смета, третья — «Условия и сроки».

## Каталог услуг (сид)

Заполняется миграцией. Примеры позиций (название · единица · базовая цена RUB):
- Растаможка легкового авто (физлицо) · шт · 25000
- Растаможка коммерческого авто · шт · 45000
- Подача декларации на товары (ДТ) · шт · 8000
- Услуги брокера · шт · 15000
- Хранение на СВХ (сутки) · сут · 800
- Сертификат СБКТС · шт · 18000
- Установка ГЛОНАСС/ЭРА · шт · 30000
- Оформление ЭПТС · шт · 6000
- Лабораторные испытания образцов · шт · 22000
- Доставка авто из Японии · шт · 90000
- Доставка авто из Кореи · шт · 75000
- Доставка авто из Китая · шт · 85000
- Ж/д доставка Владивосток → Москва · шт · 120000
- Автовоз до региона · шт · 45000
- Страхование груза · % от стоимости · 0.35
- Перевод документов · страница · 700
- Валютный контроль/оплата инвойса · шт · 5000

Пользователь может править цены/описания в отдельной вкладке «Справочники → Услуги» на странице настроек.

## Технические детали

**Миграция БД:**
```sql
-- Каталог услуг
create table public.services_catalog(
  id, name, description, unit, base_price, category, active, sort_order,
  created_at, updated_at
);

-- Заголовок КП
create table public.offers(
  id, number (serial), client_id → clients, deal_id → deals nullable,
  title, intro, template ('premium_dark'|'clean_light'|'executive'),
  currency, vat_included, valid_days, status,
  subtotal, vat_amount, total,
  sent_at, viewed_at, accepted_at,
  created_by → auth.users, created_at, updated_at
);

-- Позиции КП (снимок, не FK к каталогу — цены могут расходиться)
create table public.offer_items(
  id, offer_id → offers on delete cascade,
  name, description, unit, qty, price, amount, sort_order
);
```
Стандартные GRANT на каждую таблицу (authenticated + service_role), RLS: чтение/запись только для аутентифицированных пользователей CRM (админ/менеджер через `has_role`). Триггер `updated_at`. Автонумерация КП через sequence.

- `src/pages/admin/AdminOfferEdit.tsx` — мастер

- `src/components/admin/offers/templates/Executive.tsx`
- `src/components/admin/offers/SendOfferDialog.tsx`
- `src/lib/offerPdf.ts` — генерация PDF из шаблона (`html2canvas` + `jspdf`)
- Роуты в `src/App.tsx`, пункт меню в `src/components/admin/AdminLayout.tsx`
- В `AdminClientDetail` и `AdminDealDetail` — блок «Коммерческие предложения» со списком и кнопкой «Создать КП»
- В `AdminSettings` — новая вкладка «Услуги» для редактирования каталога

**Отправка email:** используем существующую edge-функцию `send-smtp-email`, передаём HTML письма + прикреплённый PDF (base64). Если функция ещё не поддерживает вложения — добавлю поле `attachments` на входе.

## Что не входит в этот шаг
- Публичная ссылка «клиент открыл КП в браузере» и трекинг просмотра — сделаем отдельно, если понадобится.
- Электронная подпись клиента внутри КП.
