

## План: Исправить определение возраста в утильсборе

### Проблема

В функции `calcRecyclingFee` (строка 134) возраст `'3-5'` ошибочно считается «новым» (≤3 лет):

```
const isNew = age === 'new' || age === '1-3' || age === '3-5'; // ← '3-5' лишний
```

По законодательству и ТКС, граница — **строго 3 года**:
- **≤3 лет** (`new`, `1-3`) → коэфф. 0.17 → 3 400 ₽
- **>3 лет** (`3-5`, `5-7`, `7+`) → коэфф. 0.26 → 5 200 ₽

### Исправление

| Файл | Изменение |
|---|---|
| `src/lib/calculator.ts`, строка 134 | Убрать `'3-5'` из условия `isNew`: `const isNew = age === 'new' \|\| age === '1-3';` |

Это одна строка. После исправления:
- Пример ТКС ($3000, 1999 см³, 158 л.с., 3-5 лет, физлицо) → утильсбор **5 200 ₽** ✅
- Коммерческие коэффициенты для юрлиц тоже будут корректно сдвинуты (3-5 лет = «старый»)
