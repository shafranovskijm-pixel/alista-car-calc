

## План: Исправить расчёт утильсбора и таможенного сбора по данным ТКС

### Выявленные ошибки (по скриншотам tks.ru)

**Входные данные примера:** $3 000, 1999 см³, 158 л.с., 3-5 лет, бензин, физлицо.

| Параметр | Наш калькулятор | ТКС (эталон) |
|---|---|---|
| Единая ставка (пошлина) | 2.7 €/см³ ✅ | 2.7 €/см³ |
| Утильсбор (личное) | 20000 × 33.37 = **667 400 ₽** ❌ | 20000 × 0.26 = **5 200 ₽** |
| Там. оформление | **1 550 ₽** ❌ | **2 462 ₽** |

### Причины расхождений

1. **Утильсбор:** Для физлиц, ввозящих авто для личного пользования с мощностью ≤160 л.с., действует **льготный коэффициент**: 0.17 (≤3 лет) / 0.26 (>3 лет). Итого 3 400 / 5 200 ₽. Наш код не различает льготный и коммерческий утильсбор — всегда применяет коммерческие коэффициенты.

2. **Таможенный сбор:** Шкала сборов в коде устарела. ТКС показывает 2 462 ₽ — нужно обновить тарифную сетку по Постановлению №1637 (актуальная редакция).

### Изменения

| Файл | Что |
|---|---|
| `src/lib/calculator.ts` | Переписать `calcRecyclingFee`: добавить льготный утильсбор для физлиц (≤160 л.с. ДВС / ≤80 л.с. электро) с коэфф. 0.17/0.26. Коммерческие коэффициенты оставить для юрлиц и физлиц >160 л.с. |
| `src/lib/calculator.ts` | Обновить `calcCustomsFee`: актуализировать тарифную сетку таможенных сборов |

### Новая логика утильсбора

```text
Физлицо (личное пользование):
  ДВС/гибрид, ≤160 л.с. → 20000 × 0.17 = 3 400 ₽ (≤3 лет)
                           20000 × 0.26 = 5 200 ₽ (>3 лет)
  Электро, ≤80 л.с.      → аналогичные льготные ставки
  Мощность выше порога    → коммерческие коэффициенты

Юрлицо / перепродажа:
  Коммерческие коэффициенты (текущая таблица — оставить как есть)
```
