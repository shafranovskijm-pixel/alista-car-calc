## Что делаем

Добавляем единую систему **«учебных подсказок»** на все админ-страницы и крупные блоки CRM: что это, зачем нужно, как пользоваться. И заодно переименовываем непонятные термины и причёсываем мобильную вёрстку.

### 1. Новый компонент `<HintCard />`

Единая «плашечка» в фирменном стиле — нейтрально-синий фон `primary/8`, тонкая рамка `primary/30`, иконка-лампочка `Lightbulb` слева, заголовок «Подсказка» и текст.

Свойства:
- `title` — короткий заголовок (по умолчанию «Подсказка»)
- `children` — описание (что делает раздел, какие действия, на что обратить внимание)
- `defaultCollapsed?` — на мобильных автоматически свёрнута, открывается тапом по шапке
- `storageKey?` — если задан, состояние «закрыто/открыто» запоминается в `localStorage`, и в правом углу появляется крестик «больше не показывать»

Расположение: сразу под заголовком страницы / под заголовком крупной карточки. На мобильных компактнее (меньше padding, иконка меньше).

### 2. Подсказки на каждой странице админки

| Страница | Что объясняем |
|---|---|
| **Дашборд** | Сводка: воронка, последние заявки, задачи на сегодня, выручка. Цифры обновляются автоматически. |
| **Заявки (Leads)** | Входящие обращения с сайта/мессенджеров. Менеджер квалифицирует и превращает в сделку. Drag-and-drop по статусам. |
| **Задачи** | Личный список дел менеджера: звонки, документы, доставки. Просроченные подсвечены красным. |
| **Клиенты** | База контактов. Карточка хранит реквизиты, паспорт, историю сделок и документов. Можно подтянуть данные по ИНН через DaData. |
| **Сделки** | Канбан активных автомобилей: подбор → покупка → доставка → таможня → выдача. Drag-and-drop, фильтр по менеджеру и сроку. |
| **Наши работы** | Портфолио для сайта: фото выданных авто, появляется на главной и в галерее. |
| **Каталог авто** | Карточки авто для публичного каталога: цена, фото, характеристики. |
| **Документы** | Все договоры и файлы сделок. Здесь же образец агентского договора Алиста и шаблоны. |
| **Отчёты** | Аналитика: воронка конверсии, средний цикл сделки, причины отказа, источники заявок, эффективность менеджеров. CSV-экспорт. |
| **Журнал** | Лог действий пользователей: кто что менял и когда. Для аудита и разбора спорных ситуаций. |
| **Письма** | История исходящих email из CRM (статусы, ошибки доставки). |
| **Обучение** | Пошаговый онбординг — пройдите целиком при первом запуске. |
| **Настройки** | Команда, права, шаблоны, источники, интеграции. |

### 3. Подсказки на ключевых вложенных блоках

- **Шаблоны быстрых ответов** → переименовать в **«Готовые ответы для мессенджеров и email»**, плюс HintCard: «Заготовленные тексты, которые менеджер вставляет одним кликом в чат или письмо. Переменные `{{client.name}}`, `{{deal.title}}` подставляются автоматически. Пример: "Здравствуйте, {{client.name}}! Ваш {{deal.title}} прибыл во Владивосток"».
- **Шаблоны документов** → плашка «Заготовки для счетов, доверенностей и других документов. Для агентского договора используйте системный шаблон Алиста выше».
- **Карточка клиента → блок реквизитов** → «Переключатель Физлицо/Юрлицо меняет набор полей. Кнопка "Синхронизировать с DaData" подтягивает данные по ИНН».
- **Карточка сделки → Договоры Алиста** → «Здесь хранятся все сгенерированные договоры этой сделки. Кнопка "Сгенерировать" создаёт .docx по шаблону, файл сразу появляется в списке».
- **Документы сделки → блок загрузки** → «Перетащите файлы сюда или нажмите для выбора. Поддерживаются PDF, DOCX, JPG, PNG до 20 МБ».
- **Канбан-доска (Сделки/Заявки)** → «Перетаскивайте карточки между колонками для смены статуса. Клик по карточке открывает детали».

### 4. Мобильная адаптация

Параллельно с подсказками — починить узкие места на мобиле:
- HintCard на `<sm` имеет вид свёрнутого аккордеона с иконкой и заголовком, разворачивается тапом.
- Все таблицы отчётов (`Источники заявок`, `Менеджеры`) — горизонтальный скролл с `overflow-x-auto` и фиксированной шириной столбцов, чтобы не ломались.
- Шапка отчётов с фильтром дат — на мобиле в одну колонку, кнопка CSV полной ширины.
- Кнопки действий в `TemplatesManager`, `AlistaContractSample`, `AlistaContractsList` — `flex-wrap` + полная ширина на мобиле.
- Канбан-доски и сейчас скроллятся; проверить только что HintCard над ними не растягивает контейнер.

### 5. Текстовые правки терминологии

- «Шаблоны быстрых ответов» → «Готовые ответы для мессенджеров и email».
- В переменных вместо `{{client.name}}` (точечная нотация) везде использовать единый стиль, и подписать каждую переменную человеческим описанием в строке-подсказке: `{{client.name}} — имя клиента`, `{{deal.title}} — название сделки` и т.д.
- В пустом состоянии «Шаблонов пока нет» добавить пример готового шаблона на скриншоте/в тексте.

## Технические детали

- Новый файл: `src/components/admin/HintCard.tsx` — переиспользуемый компонент.
- Подключаем по одному `<HintCard>` в каждую страницу `src/pages/admin/Admin*.tsx` и в крупные `src/components/admin/*` (TemplatesManager, документные карточки и т.д.). По одной плашке на страницу/секцию — не засоряем.
- В `localStorage` ключи вида `hint_dismissed_<page>`; добавим в Настройки кнопку «Показать все подсказки заново» (сброс всех ключей).
- Стиль HintCard вписан в текущий design system (semantic tokens `primary`, `muted-foreground`, `border`), без хардкода цветов — работает и в светлой, и в тёмной теме.

## Что НЕ делаем

- Не переделываем сами страницы и их функциональность — только добавляем плашки, переименовываем «Шаблоны быстрых ответов» и чиним конкретные мобильные косяки.
- Не трогаем компонент `OnboardingGuide` — он остаётся отдельным пошаговым обучением; плашки на страницах ему не дублируют, а служат напоминалкой по конкретному разделу.
