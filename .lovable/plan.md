

## План: замена favicon

Проблема: в `index.html` отсутствует тег `<link rel="icon">`, поэтому отображается дефолтный favicon Lovable (сердечко).

### Что нужно

Загруженное изображение — это скриншот проблемы, а не файл для favicon. Нужен файл иконки.

### Вопрос

Есть ли у вас файл favicon (PNG, SVG или ICO) с логотипом ALISTA? Если да — загрузите его, и я установлю. Если нет — могу:
1. Сгенерировать текстовый favicon с буквой «A» в стиле сайта
2. Использовать SVG-иконку автомобиля

### Техническая реализация

1. Скопировать файл в `public/favicon.png`
2. Добавить в `index.html`:
```html
<link rel="icon" href="/favicon.png" type="image/png">
```
