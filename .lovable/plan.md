

## План: фоновое изображение для Hero + декоративные элементы

Сайт сейчас визуально минималистичный — тёмный фон с градиентами, без изображений и декора. Добавим атмосферу.

---

### Шаг 1. Сгенерировать фоновое изображение для Hero

Через AI-генерацию создать атмосферное изображение: порт Владивостока / контейнеры / автомобили на причале — тёмное, с синими тонами, подходящее под цветовую схему сайта (тёмно-синий + cyan accent). Изображение будет полупрозрачным фоном Hero-секции с overlay-градиентом поверх для читаемости текста.

### Шаг 2. Добавить декоративные CSS-элементы по всему сайту

В `index.css` добавить:
- **Анимированные градиентные orbs** (размытые цветные круги) — плавающие в фоне секций
- **Сетка/grid-pattern** — тонкая полупрозрачная сетка как текстура фона
- **Градиентные линии-разделители** между секциями вместо простых `border-t`

### Шаг 3. Интегрировать в Index.tsx

- Hero: фоновое изображение с `object-cover`, поверх — тёмный gradient overlay + blur
- Floating orbs: анимированные `motion.div` с gradient backgrounds, `blur-3xl`, absolute positioning — в Hero, Features, FAQ секциях
- Grid-pattern как `::before` pseudo-element на секциях

### Шаг 4. Добавить декор на другие страницы

Переиспользовать декоративные orbs и grid-pattern в Layout.tsx или отдельным компонентом `BackgroundDecor`, чтобы все страницы получили визуальную глубину.

---

### Технические детали

- Фоновое изображение: `src/assets/hero-bg.jpg`, AI-генерация через `lovable_ai.py --image`
- Новый компонент: `src/components/BackgroundDecor.tsx` — анимированные orbs с framer-motion
- Файлы для редактирования: `Index.tsx`, `Layout.tsx`, `index.css`
- Orbs: 3-4 штуки, `position: absolute`, `filter: blur(80-120px)`, `opacity: 0.15-0.3`, анимация `y` через framer-motion с `repeat: Infinity`
