## Цель

Превратить CRM ALISTA из «дашборда с нулями» в инструмент, в котором менеджер автоимпорта работает быстро и интуитивно. Референсы: Pipedrive (канбан), Linear (таблицы и хоткеи), Attio (карточки), HubSpot (таймлайны).

Делаем 5 этапов. Каждый — самостоятельный, можно остановиться на любом.

---

## Этап 1. Дизайн-система и навигация (фундамент)

Меняем всю админку, не трогая бизнес-логику.

**Сайдбар** (`src/components/admin/AdminLayout.tsx`):
- Перевод на shadcn `Sidebar` с `collapsible="icon"` — сворачивается в иконки.
- Группы: «Продажи» (Дашборд, Заявки, Клиенты, Сделки), «Каталог» (Наши работы, Каталог авто), «Документы» (Документы, Отчёты), «Система» (Настройки).
- Бейджи с числами рядом с пунктами «Заявки» (новые), «Сделки» (требуют действия).
- Активный пункт — neon-blue акцент + левая полоска.

**Топбар:**
- Глобальный поиск `Cmd/Ctrl+K` (shadcn `Command`) — поиск по заявкам, клиентам, сделкам, авто, переход на карточку.
- Колокольчик уведомлений (поповер со списком: новая заявка, просроченная задача).
- Курсы валют (USD/EUR/JPY/CNY) компактным блоком — данные уже тянутся с ЦБ.
- Аватар пользователя + выход.

**Глобальные UI-улучшения:**
- `EmptyState` компонент с иконкой, текстом, CTA — заменяет «Пусто».
- `Skeleton` лоадеры вместо «Загрузка…» во всех админ-страницах.
- `sonner` toast на все мутации (сохранено / ошибка).
- Hover-эффект на строках таблиц и карточках.
- Компакт-режим (переключатель плотности, сохранять в localStorage).
- Цветовой ребаланс бейджей: текущий этап — насыщенный, остальные — приглушённые.

## Этап 2. Новый дашборд

Полностью переписываем `src/pages/admin/AdminDashboard.tsx`.

**Сверху — «Мои задачи на сегодня»:**
- Просроченные перезвоны, встречи сегодня, заявки без касания >24ч.
- Каждая строка кликабельна, кнопка «Взять в работу» / «Отметить выполнено».

**KPI-карточки (4 шт.) с дельтой:**
- Новые заявки (+12% к прошлой неделе, спарклайн).
- Конверсия лид→успех (%).
- Активные сделки (сумма бюджета).
- Выручка за месяц (RUB).

**Воронка сделок (horizontal funnel):**
- Recharts `FunnelChart` по этапам `DEAL_STAGES`.
- Подсветка узких мест (где конверсия падает >50%).

**График заявок за 30 дней:**
- Recharts `AreaChart` с разбивкой по источникам (UTM source).

**«Зависшие» лиды:**
- Список заявок без активности >3 дней, с быстрым «Взять» / «Перезвонить».

**Последние действия:**
- Оставляем, но добавляем иконку по типу события и аватар автора.

Recharts уже в проекте (`src/components/ui/chart.tsx`), доустановка не нужна.

## Этап 4. Карточка сделки/лида в 3 колонки

Переписываем `src/pages/admin/AdminLeadDetail.tsx` и `AdminDealDetail.tsx` по общему шаблону.

**Левая колонка (320px):**
- Аватар + ФИО клиента, телефон/email с кнопкой «позвонить/написать».
- Источник (UTM), tag, ответственный (selectable).
- Авто/предмет интереса.
- Бюджет, валюта.
- Связанные сделки / лиды.

**Центр (flex-1) — таймлайн:**
- Хронологический фид: смены статуса, заметки, звонки, задачи, документы, письма.
- Сверху — быстрые табы: «Заметка / Задача / Звонок / Документ».
- Inline-форма добавления — без модалок.
- Источник данных: `audit_log` + `lead_status_history` / `deal_stage_history` + новая таблица `lead_activities` (см. ниже).

**Правая колонка (360px):**
- Чек-лист текущего этапа (для сделок — что должно быть сделано на этапе «Оплата», «Доставка» и т.д.).
- Расчёт калькулятора из `calc_snapshot` (для лидов с заполненным полем) — красивая разбивка пошлин.
- Документы (список с превью).
- На сделке — связанный клиент и связанный лид.

**Новая таблица `lead_activities`** для заметок/задач/звонков:
- `id`, `lead_id` (nullable), `deal_id` (nullable), `client_id` (nullable)
- `type` (note | task | call | meeting)
- `title`, `body`, `due_at`, `done_at`, `created_by`
- RLS: видят все авторизованные, редактируют автор и админ.

## Этап 5. Прокачка таблицы заявок (Linear-style)

`src/pages/admin/AdminLeads.tsx` (режим «Таблица»):

- **Inline-смена статуса:** клик по бейджу → поповер со списком статусов → апдейт.
- **Bulk actions:** чекбоксы в строках, плавающая панель снизу при выделении: сменить статус, назначить менеджера, экспорт в CSV, удалить.
- **Сохранённые фильтры (вьюхи):** «Мои», «Новые сегодня», «Просрочка перезвона», «За неделю». Храним в localStorage.
- **Настраиваемые колонки:** дропдаун «Колонки» с чекбоксами, сохранение в localStorage.
- **SLA-индикатор:** левая цветная полоска у строки — зелёная (свежая), жёлтая (>12ч), красная (>24ч без касания).
- **Сортировка по любой колонке.**
- **Хоткеи:** `N` — новая заявка, `/` — фокус в поиск, `J/K` — навигация по строкам, `Enter` — открыть.

Аналогично для `AdminDeals.tsx` и `AdminClients.tsx` (упрощённо).

## Порядок работы

1. **Этап 1** (дизайн-система + сайдбар + топбар) — закладывает основу для всего.

4. **Этап 3** (Kanban) — визуальный wow-эффект.
5. **Этап 4** (карточка + таймлайн + миграция БД) — самое объёмное, в конце.

После каждого этапа — проверяем preview, фиксим. Если хочется остановиться раньше — останавливаемся.
