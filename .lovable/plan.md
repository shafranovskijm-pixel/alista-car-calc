Пройдусь по всем разделам админки и сайта, соберу список улучшений визуала и функционала. Ниже — что я уже вижу из кода и что предлагаю сделать. Реализовывать буду этапами, по вашему приоритету.

### 1. Дашборд `/admin`

**Что улучшить (визуал):**
- Карточки KPI одинаковой высоты, добавить мини-спарклайны (динамика за 14 дней).
- Цветовые индикаторы тренда (рост/падение к прошлой неделе со стрелкой).
- Skeleton-загрузка вместо «Загрузка...».

**Функционал:**
- Виджет «Воронка продаж» (заявка → квалификация → договор → оплата → доставка).
- Виджет «Мои задачи на сегодня» уже есть — добавить быстрое «отметить выполненной» в один клик.
- Фильтр периода (7/30/90 дней, кастомный).
- Виджет «Курсы валют» в дашборде (не только в шапке), с историей за неделю.

### 2. Заявки `/admin/leads`

**Визуал:**
- Канбан-доска как альтернатива списку (drag&drop по статусам).
- Цветовые бейджи статусов единые везде (new/in_progress/won/lost).
- Аватарка ответственного менеджера в строке.

**Функционал:**
- Массовые действия: выбрать несколько → сменить статус / назначить менеджера / удалить.
- Inline-редактирование статуса прямо в таблице.
- Быстрый ответ — кнопка «Позвонить» (tel:) и «WhatsApp» (wa.me) рядом с телефоном.
- SLA-таймер: подсветка лидов без ответа >2 часов красным.
- Импорт лидов из CSV.

### 3. Карточка лида / сделки

**Визуал:**
- Двухколоночный layout: слева данные, справа таймлайн активности (сейчас всё в одну колонку).
- Sticky-панель действий сверху при скролле.

**Функционал:**
- Конвертация «Лид → Сделка + Клиент» одной кнопкой с предзаполнением.
- История изменений полей (кто/когда сменил статус, цену).
- Прикрепление файлов прямо в карточку (фото авто от клиента, скрины переписки).
- Поле «Следующий шаг + дата» — автосоздание задачи.

### Как двигаться дальше

Я могу:
1. **Сделать всё по списку поэтапно** — начать с самого важного (канбан сделок + воронка дашборда + калькулятор маржи) — это сразу даёт деньги.
2. **Сначала визуальная полировка** — единые статусы, skeleton-загрузки, мобильная адаптивность админки.
3. **Сначала функционал, который сэкономит время** — массовые действия в лидах, шаблоны документов с автозаполнением, чек-листы этапов.

Скажите, какой блок брать первым (или какие пункты выкинуть как ненужные) — и я составлю детальный план реализации на этот спринт.
