

## Аудит таможенного калькулятора: выявленные проблемы

Я проверил логику калькулятора (`src/lib/calculator.ts`) и сопоставил её с актуальными нормативными документами. Обнаружен ряд серьёзных несоответствий.

---

### 1. Утилизационный сбор — критически устарел

**Текущий код:** Использует старые коэффициенты (0.17 для новых авто физлиц = 3 400 ₽).

**Реальность (с 01.12.2025, Постановление № 1713):** Коэффициенты увеличены в десятки раз. Расчёт теперь зависит от объёма двигателя, мощности (кВт) и типа двигателя. Для физлиц льготные коэффициенты больше не действуют в прежнем виде. Пример: авто 2.0л новый — коэффициент ~33.37 (вместо 0.17), итого ~667 400 ₽ вместо 3 400 ₽.

**Исправление:** Полностью переписать `calcRecyclingFee` с актуальными коэффициентами по Постановлению 1291 в редакции 1713.

### 2. Ставки акцизов — устарели

**Текущий код (2024):** 55, 531, 869, 1482, 1534, 1584 ₽/л.с.

**Актуальные ставки (2026, ФЗ № 425-ФЗ):**
- 90–150 л.с. → 64 ₽
- 150–200 л.с. → 613 ₽
- 200–300 л.с. → 1 004 ₽
- 300–400 л.с. → повышены пропорционально
- 400–500, 500+ → повышены

**Исправление:** Обновить все ставки в `calcExcise`.

### 3. НДС — неверная ставка

**Текущий код:** 20%

**С 01.01.2026:** Ставка НДС = **22%** (ФЗ № 425-ФЗ, налоговая реформа 2026).

**Исправление:** Изменить `0.20` на `0.22`.

### 4. Таможенный сбор — устарел

**С 01.01.2025** (Постановление 1637) введены новые ставки таможенных сборов для товаров личного пользования. Текущие значения в `calcCustomsFee` приблизительно соответствуют старой шкале, но нуждаются в сверке.

**Исправление:** Обновить шкалу сборов по Постановлению 1637.

### 5. Пошлины для юрлиц — упрощены

**Текущий код:** Фиксированные 15% для авто, 10% для грузовиков.

**Реальность:** Ставки зависят от кода ТН ВЭД, объёма двигателя, возраста ТС. Например, для авто старше 7 лет — 1.4–3.2 €/см³.

**Исправление:** Добавить дифференцированные ставки для юрлиц по основным категориям.

### 6. Курсы валют захардкожены

Курсы (EUR=100, USD=92, JPY=0.62) зафиксированы в коде и быстро устаревают.

**Исправление:** Добавить дату актуальности и предупреждение. Опционально — API ЦБ РФ.
