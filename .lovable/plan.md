## Аудит CRM: что пропустили и что улучшить

Разделил на блоки по приоритету. Жду от вас отметки, что включаем — оформлю в этапы по 2–3 пункта.

---

### 🔥 Критично (быстро добавляет ценность)

1. **Задачи и напоминания как отдельная сущность**
   Сейчас задачи живут только внутри активностей лида. Нужны: страница «Мои задачи», виджет «На сегодня / Просрочено» на дашборде, push-уведомления в колокольчик за 15 мин до дедлайна.

2. **Аналитика воронки (Funnel)**
   В «Отчётах» добавить: конверсия Lead → Deal → Won по шагам, средний цикл сделки, причины отказа (поле `lost_reason`), сравнение периодов, разбивка по менеджерам и источникам UTM.

3. **Связь Авто ↔ Сделка**
   В БД `cars` и `deals` не связаны. Добавить `deal_id` или join, чтобы в карточке сделки видеть/прикреплять конкретное авто из каталога, а в карточке авто — историю «кому продано».

4. **Сохранённые представления (Views) в таблицах**
   Фильтры есть, но без сохранения. Сделать именованные пресеты: «Мои горящие», «Без активности 3+ дня», «Этот месяц», — общие и личные.

5. **Импорт/экспорт CSV**
   Экспорт лидов/сделок/клиентов в CSV (с учётом фильтров). Импорт лидов из CSV с маппингом колонок.

---

### ⚙️ Функционал

6. **Шаблоны быстрых ответов** (email/Telegram/WhatsApp) с переменными `{{client.name}}`, `{{deal.budget}}` — отправка в один клик из карточки заявки.

7. **Telegram-уведомления и привязка чата** — менеджер указывает `chat_id`, бот шлёт ему новые заявки и просрочки.

8. **Триггеры/автоматизации** (мини-конструктор): «если лид > 2 дня без действий — назначить задачу», «если этап = Оплата — создать счёт автоматически».

9. **Журнал аудита UI** — таблица `audit_log` в БД есть, но интерфейса нет. Страница «Журнал» с фильтрами по пользователю/сущности/дате.

10. **Роли и команда** — страница «Команда» в настройках: приглашение по email, выдача ролей (admin/manager/viewer), деактивация. Расширить `user_roles`.

11. **Email-рассылки и шаблоны писем клиентам** через Resend: подтверждение заявки, статус доставки авто, поздравления.

12. **Тэги и кастомные поля** для лидов/клиентов/сделок (типа: «VIP», «лизинг», «корпоратив»). Фильтрация по тэгам.

13. **Дубли клиентов** — детектор по телефону/email при создании лида + кнопка «Объединить дубли».

14. **Лента активности по всей системе** — отдельная страница `/admin/feed` с фильтрами (кто что сделал, по чему).

15. **Документы — версионирование и e-sign** — история версий, статус «отправлен / подписан», простая подпись через ссылку клиенту.

---

### 🎨 Интерфейс / UX

16. **Командная палитра расширить** (Cmd+K) — добавить действия, а не только сущности: «Создать лида», «Перейти к отчётам», «Сменить статус…».

17. **Inline-редактирование везде** — двойной клик по полю в таблице правит без открытия карточки (для бюджета, имени, телефона).

18. **Hover-превью** карточки при наведении на ссылку лида/клиента/сделки (как в Linear).

19. **Тёмная/светлая тема + переключатель** — сейчас фиксирована тёмная.

20. **Адаптив для планшета и мобильного** — таблицы и Канбан переключаются в карточные списки; шапка с гамбургером.

21. **Skeleton loaders вместо «Загрузка...»** на всех страницах + плавные transition между состояниями.

22. **Empty states с действием** — у нас есть `EmptyState`, но не везде; добавить иллюстрацию + кнопку «Создать первого».

23. **Onboarding-обучение → подсветка элементов на странице** (joyride-style) — кнопка «Показать на странице» из шага обучения подсвечивает реальный элемент.

24. **Дашборд с настраиваемыми виджетами** — drag&drop, показать/скрыть KPI.

25. **Сравнение валют в шапке расширить** — клик по тикеру открывает мини-график за 30 дней (данные ЦБ).

26. **Уведомления в реальном времени** — toast при новой заявке у текущего менеджера, звуковой сигнал (опционально).

---

### 🛡️ Безопасность и качество

27. **2FA для админа** (TOTP).
28. **Сессии и устройства** — список активных сессий, «выйти везде».
29. **Логирование критичных действий** (удаление, экспорт) с обязательной причиной.
30. **RLS-аудит** — пройти линтером Supabase, закрыть warning'и.
31. **Тесты** — vitest для критичных хуков (статусы, конвертация лида, расчёт маржи).

---

### 📊 Бэкенд / данные

32. **Поле `lost_reason`** + справочник причин на `leads` и `deals`.
33. **`assigned_to_id`** у `deals` (сейчас только у `leads`?) — проверить и унифицировать.
34. **`source` UTM-метки** в отдельную таблицу `lead_sources` для отчётов.
35. **Storage для документов и фото авто** — bucket с RLS, прямые ссылки.
36. **Edge function для генерации PDF** документов из шаблонов (puppeteer/pdfme).

- **Этап B** (1 заход): аналитика воронки + причины отказа + сравнение менеджеров.
- **Этап C** (1 заход): связь Авто↔Сделка + сохранённые представления + экспорт CSV.
