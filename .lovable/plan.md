## Что есть в данных

- `photos.rar` — 686 миниатюр (~58 МБ), названия вида `photo_NNNN@DD-MM-YYYY_HH-MM-SS_thumb.jpg`.
- `messages.html` … `messages4.html` — экспорт канала @AutoXvat. Каждое сообщение содержит группу фото (одна «карточка авто») и текст с маркой/моделью/годом/двигателем/пробегом/ценой/контактом.

То есть фото уже «осмысленные»: к каждой группе можно вытащить заголовок (Haval M6 Plus, 2021, 1.290.000 ₽ и т.д.).

## Что построим

### 1. Парсер экспорта (одноразовый скрипт, локально)

`scripts/import-telegram.ts`:
- Читает 4 html через cheerio.
- Группирует сообщения по «постам»: первое сообщение с `from_name` + последующие `joined`-сообщения = один лот.
- Из текста вытаскивает: марку/модель (первая строка с 🚘 или жирным), год, двигатель, привод, пробег, цену (regex по «₽»), статус (Китай/Япония/в наличии).
- Из `media_wrap` собирает список `photos/photo_X@...jpg`.
- На выходе — `public/works/index.json` со списком работ:
  ```ts
  { id, slug, title, date, price, summary, photos: ["/works/img/photo_X.jpg", ...] }
  ```

### 2. Заливка фото

Вариант, который рекомендую: **Lovable Assets (CDN)**.
- Распаковываем rar в `/tmp/photos`.
- Скрипт прогоняет каждое фото через `lovable-assets create` и пишет `public/works/manifest.json` с url'ами.
- В репозиторий бинарники не попадают, 58 МБ уходят в CDN.

Альтернатива: Supabase Storage bucket `works` (public). Дороже по запросам, но проще обновлять из админки. Скажи, если хочешь так — тогда вместо JSON будут таблицы `works` + `work_photos`, и админ-раздел `/admin/works` для редактирования (название, цена, перетаскивание фото, скрыть/опубликовать).

По умолчанию делаю **CDN+JSON** — быстро, бесплатно, ничего не ломает.

### 3. Раздел «Наши работы»

Новый маршрут `/works` (+ ссылка в шапке/футере и блок-тизер на главной с 6 карточками и кнопкой «Все работы»).

Страница:
- Хедер: «700+ оформленных авто» (уже в core memory), фильтры (страна, год, цена) — опционально, можно во второй итерации.
- Masonry-сетка карточек: обложка (1-е фото лота) + название + цена + дата.
- Hover: лёгкий glow в духе текущего дизайна (`hover-lift`, `box-glow`).
- Клик → модалка (Dialog + Embla Carousel) со всеми фото лота, описанием, ценой и кнопкой «Заказать похожее» → ведёт на калькулятор/контакты.
- Lazy-load изображений, пагинация по 24 (кнопка «Показать ещё» или infinite scroll через IntersectionObserver).

Существующий `Gallery.tsx` (6 заглушек) на главной заменим на превью из новых данных.
