# Яндекс Метрика

Интеграция активируется только после задания реального номера счётчика:

```text
VITE_YANDEX_METRIKA_ID=12345678
```

В интерфейсе счётчика нужно создать четыре цели типа «Целевое событие» с точными идентификаторами:

- `lead_form_success` — заявка действительно записана в CRM;
- `phone_click` — переход по номеру телефона;
- `whatsapp_click` — переход в WhatsApp;
- `telegram_click` — переход в Telegram.

До согласия посетителя скрипт Метрики не загружается; выбор можно изменить кнопкой «Настройки аналитики». Вебвизор отключён, данные полей формы в цели не передаются. Если переменной `VITE_YANDEX_METRIKA_ID` нет, интеграция полностью бездействует.
