# Telegram-канал → каталог автомобилей

Новые посты о машинах в канале (по умолчанию `@alistaavto25`) автоматически становятся карточками автомобилей на сайте (`cars` + `car_photos`).

## Инструкция для клиента (Денис)

1. Откройте канал @alistaavto25 → Управление каналом → Администраторы → Добавить администратора.
2. Найдите **@alistaru_catalog_bot** и добавьте его. Права можно снять все — нажмите «Сохранить».
3. Всё. Дальше публикуйте как сейчас: один пост или альбом с одной машиной сам появится на сайте.

## Как распознаются посты (для нас)

- **Обычные посты (по умолчанию).** Берутся только явно указанные данные: марка (из списка известных) и модель — из первой строки с маркой; год — «2021г.», «Год: …», «Производство: 05.2022», «Дата производства: 09.2022» или отдельная календарная строка «06.2022»; страна — флаг 🇯🇵/🇰🇷/🇨🇳, поле страны или явное «из Японии/Кореи/Китая». Страна не угадывается по марке, рулю или флагу производителя. Пробег, объём, л.с., топливо и коробка — только если написаны; дробная мощность вроде 149,6 л.с. не округляется и не превращается в 6 л.с.
- Рекламный footer «ALISTA — авто из Японии, Китая и Кореи…» не участвует в извлечении страны, марки, года, цены или статуса. Полное исходное описание, включая footer, сохраняется без сокращений.
- Цена может быть одной суммой с валютой (₽/руб/RUB, JPY/иен, CNY/юаней, «1.650.000 ₽», «1,9 млн ₽»). При разбивке выбирается только явный «ИТОГО» либо однозначный итог «под ключ»; равнозначные разные цены отклоняются. Если у одной уверенно распознанной машины цены нет, сохраняется `price = null` («Цена по запросу»), а не 0 или выдуманная сумма.
- Без марки и ценовых признаков (контакты, новости) — игнорируются молча.
- Подборки (слово «подборка», нумерованный список, несколько марок) — пропуск с причиной в журнале.
- Нет года/страны, несколько разных цен/годов/стран, отрицательная или некорректная цена, незаполненное `[указать]`, неоднозначный знак ¥ — пропуск с причиной, на сайт не публикуется. Явный CNY/JPY рядом с ¥ разрешается и не путает валюты.
- «Продан» в фактической части текста или `#продано` — проданная, `#скрыть` — черновик. Правка поста обновляет ту же карточку.
- **Строгий шаблон (запасной вариант).** Пост с `#авто` и строками `Марка:`, `Модель:`, `Год:`, `Страна:`, `Цена:` (+ необязательные `Пробег:`, `Двигатель:`, `Мощность:`, `Коробка:`, `Топливо:`, `Статус:`) разбирается строго по полям.
- Старые посты канала не переносятся — только новые после подключения.

## Техническая инструкция (для нас)

Бот `@alistaru_catalog_bot` зарегистрирован владельцем. Токен вносится только в CRM → Настройки → Telegram (доступно лишь admin).

1. Вставить токен, канал `@alistaavto25` → **«Подготовить подключение»**. Сервер проверяет getMe, сохраняет токен в закрытой таблице и регистрирует webhook с `secret_token` и `allowed_updates = channel_post, edited_channel_post, my_chat_member`.
2. Если бот уже администратор канала — импорт включается сразу. Иначе статус **«Ожидаем добавления бота в канал»**.
3. Когда клиент добавит бота, Telegram пришлёт `my_chat_member`. После проверки секрета, `chat.type = channel`, username канала, `user.id = bot_id` и статуса `administrator` сервер привязывает точный `channel_id` и включает импорт. Уже привязанный id другой канал не перепривяжет.
4. Снятие бота/прав — импорт выключается (повторное добавление снова включит). **«Отключить импорт»** выключает и автовключение, поздний `my_chat_member` его не вернёт; включить снова — кнопкой «Включить импорт» или «Подготовить подключение».
5. Боту не выдаются никакие права на сайте.

## Как это работает

- `telegram-webhook` принимает только запросы с правильным `X-Telegram-Bot-Api-Secret-Token` (случайный секрет, создаётся при сохранении) и только `channel_post`/`edited_channel_post` из сохранённого `channel_id`. Чужие чаты, личные сообщения и выключенный импорт сайт не меняют.
- Повторы Telegram гасятся по `update_id`; создание/правка карточки идёт через `telegram_upsert_car` под advisory lock на пост; версия текста — пара (`edit_date`, `update_id`), более старая не перезаписывает более новую.
- Временная ошибка скачивания/сохранения фото возвращает Telegram 500 — апдейт не помечается обработанным и будет доставлен повторно (повтор идемпотентен). Недопустимый тип/размер помечается `photo_error` и не повторяется.
- Фото скачиваются сервером только после того, как пост распознан как одна машина, проверяются (JPG/PNG/WebP, ≤10 МБ, ≤20 на машину), сохраняются в приватный bucket `cars` по детерминированному пути `<car_id>/tg-<message_id>-<file_unique_id>.<ext>`; `telegram_sync_photos` добавляет их без дублей и назначает одну обложку. Ссылки `api.telegram.org/file/bot…` нигде не сохраняются, ошибки очищаются от токена.
- Каталог и главная подписаны на realtime-изменения `cars`/`car_photos` и дополнительно спокойно обновляются раз в 90 секунд, если realtime недоступен через прокси.
- Все `telegram_*` таблицы недоступны ролям `anon`/`authenticated`; читает их только серверная роль.
