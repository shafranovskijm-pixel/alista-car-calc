# Telegram-канал → каталог автомобилей

Новые посты с тегом `#авто` в канале (по умолчанию `@alistaavto25`) автоматически становятся карточками автомобилей на сайте (`cars` + `car_photos`).

## Технический статус подключения

| Что | Статус |
|---|---|
| Таблицы, функции БД, realtime для `cars`/`car_photos` | применены |
| Функция `telegram-webhook` (публичная, `verify_jwt = false`) | развёрнута, без секрета отвечает 401 |
| Функция `telegram-admin` (только admin) | развёрнута, без входа отвечает 403 |
| Вкладка «Настройки → Telegram» в CRM | в коде, во фронтенде ещё не опубликована |
| Бот в @BotFather, токен, бот-админ в канале | **не сделано — за владельцем** |
| Импорт | выключен, пока не пройдена проверка getMe/getChat/getChatMember |

## Подключение (владелец, один раз)

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя и username. Скопируйте токен.
2. Откройте канал → Управление каналом → Администраторы → Добавить → найдите бота. Права можно снять все: боту нужно только быть администратором, чтобы получать новые посты. Публиковать от его имени не нужно.
3. На сайте: CRM → Настройки → **Telegram** (видна только администраторам). Вставьте токен, проверьте канал `@alistaavto25`, нажмите **«Проверить и сохранить»**. Сайт проверит токен, канал и что бот — администратор.
4. Нажмите **«Включить импорт»**. Статус webhook должен стать «работает».
5. Сделайте тестовый пост по шаблону ниже и проверьте «Последние импорты».

Токен вводится только в этой вкладке. Он хранится на сервере в закрытой таблице, в браузер возвращаются лишь последние 4 символа. Пересылать посты боту в личку не нужно.

## Инструкция для Дениса

Публикуйте как обычно, но добавляйте `#авто` и строки шаблона:

```
#авто
Марка: Toyota
Модель: C-HR
Год: 2020
Страна: Япония
Цена: 1 945 000 ₽
Пробег: 42 000 км
Двигатель: 1.2
Мощность: 116
Коробка: Вариатор
Топливо: Бензин
Статус: Под заказ

Любой ваш текст описания — он сохранится целиком.
```

- **Обязательно:** Марка, Модель, Год, Страна (Япония/Корея/Китай), Цена с валютой (RUB/₽/JPY/CNY). Без них пост не публикуется, причина появится в журнале CRM.
- **Необязательно:** Пробег, Двигатель, Мощность, Коробка (АКПП/МКПП/Вариатор/Робот/DCT), Топливо (Бензин/Дизель/Гибрид/Электро/Газ), Статус (Под заказ/В наличии/В пути/Продан; по умолчанию «Под заказ»).
- Один пост или один альбом = одна машина. Фото альбома идут в том же порядке, первое — обложка.
- Отредактировали цену, статус или текст в канале — та же карточка на сайте обновится.
- `#продано` (или `Статус: Продан`) — машина помечается проданной. `#скрыть` — машина убирается с сайта.
- Удаление поста в канале на сайт **не** передаётся (Telegram не сообщает ботам об удалении). Скройте машину через `#скрыть` или в CRM.
- Посты без `#авто` и старые посты (опубликованные до подключения) не импортируются.

## Как это работает

- `telegram-webhook` принимает только запросы с правильным `X-Telegram-Bot-Api-Secret-Token` (случайный секрет, создаётся при сохранении) и только `channel_post`/`edited_channel_post` из сохранённого `channel_id`. Чужие чаты, личные сообщения и выключенный импорт сайт не меняют.
- Повторы Telegram гасятся по `update_id`; создание/правка карточки идёт через `telegram_upsert_car` под advisory lock на пост; более старая версия текста (`edit_date`) не перезаписывает более новую.
- Фото скачиваются сервером только после того, как пост распознан как `#авто`, проверяются (JPG/PNG/WebP, ≤10 МБ, ≤20 на машину), сохраняются в приватный bucket `cars` по детерминированному пути `<car_id>/tg-<message_id>-<file_unique_id>.<ext>`; `telegram_sync_photos` добавляет их без дублей и назначает одну обложку. Ссылки `api.telegram.org/file/bot…` нигде не сохраняются, ошибки очищаются от токена.
- Каталог и главная подписаны на realtime-изменения `cars`/`car_photos` и дополнительно спокойно обновляются раз в 90 секунд, если realtime недоступен через прокси.
- Все `telegram_*` таблицы недоступны ролям `anon`/`authenticated`; читает их только серверная роль.
