# Telegram-канал → каталог автомобилей

Новые посты с тегом `#авто` в канале (по умолчанию `@alistaavto25`) автоматически становятся карточками автомобилей на сайте (`cars` + `car_photos`).

## Инструкция для клиента (Денис)

1. Откройте канал @alistaavto25 → Управление каналом → Администраторы → Добавить администратора.
2. Найдите **@alistaru_catalog_bot** и добавьте его. Права можно снять все — нажмите «Сохранить».
3. Публикуйте машины как обычно по примеру:

```
#авто
Марка: Toyota
Модель: C-HR
Год: 2020
Страна: Япония
Цена: 1 945 000 ₽
Пробег: 42 000 км
Статус: Под заказ
Ваш текст описания.
```

- Обязательно: Марка, Модель, Год, Страна (Япония/Корея/Китай), Цена с одной валютой (₽/RUB, JPY/иен, CNY/юаней; можно «1,5 млн ₽», «850 тыс. руб»).
- По желанию: Пробег, Двигатель, Мощность, Коробка, Топливо, Статус (Под заказ/В наличии/В пути/Продан).
- Один пост или альбом = одна машина, первое фото — обложка. Правка поста обновляет машину.
- `#продано` — продана, `#скрыть` — убрать с сайта. Удаление поста в канале на сайт не передаётся.

## Техническая инструкция (для нас)

Бот `@alistaru_catalog_bot` зарегистрирован владельцем. Токен вносится только в CRM → Настройки → Telegram (доступно лишь admin).

1. Вставить токен, канал `@alistaavto25` → **«Подготовить подключение»**. Сервер проверяет getMe, сохраняет токен в закрытой таблице и регистрирует webhook с `secret_token` и `allowed_updates = channel_post, edited_channel_post, my_chat_member`.
2. Если бот уже администратор канала — импорт включается сразу. Иначе статус **«Ожидаем добавления бота в канал»**.
3. Когда клиент добавит бота, Telegram пришлёт `my_chat_member`. После проверки секрета, `chat.type = channel`, username канала, `user.id = bot_id` и статуса `administrator` сервер привязывает точный `channel_id` и включает импорт. Уже привязанный id другой канал не перепривяжет.
4. Снятие бота/прав — импорт выключается (повторное добавление снова включит). **«Отключить импорт»** выключает и автовключение, поздний `my_chat_member` его не вернёт; включить снова — кнопкой «Включить импорт» или «Подготовить подключение».
5. Боту не выдаются никакие права на сайте.

## Как это работает

- `telegram-webhook` принимает только запросы с правильным `X-Telegram-Bot-Api-Secret-Token` (случайный секрет, создаётся при сохранении) и только `channel_post`/`edited_channel_post` из сохранённого `channel_id`. Чужие чаты, личные сообщения и выключенный импорт сайт не меняют.
- Повторы Telegram гасятся по `update_id`; создание/правка карточки идёт через `telegram_upsert_car` под advisory lock на пост; версия текста — пара (`edit_date`, `update_id`), более старая не перезаписывает более новую.
- Временная ошибка скачивания/сохранения фото возвращает Telegram 500 — апдейт не помечается обработанным и будет доставлен повторно (повтор идемпотентен). Недопустимый тип/размер помечается `photo_error` и не повторяется.
- Фото скачиваются сервером только после того, как пост распознан как `#авто`, проверяются (JPG/PNG/WebP, ≤10 МБ, ≤20 на машину), сохраняются в приватный bucket `cars` по детерминированному пути `<car_id>/tg-<message_id>-<file_unique_id>.<ext>`; `telegram_sync_photos` добавляет их без дублей и назначает одну обложку. Ссылки `api.telegram.org/file/bot…` нигде не сохраняются, ошибки очищаются от токена.
- Каталог и главная подписаны на realtime-изменения `cars`/`car_photos` и дополнительно спокойно обновляются раз в 90 секунд, если realtime недоступен через прокси.
- Все `telegram_*` таблицы недоступны ролям `anon`/`authenticated`; читает их только серверная роль.
